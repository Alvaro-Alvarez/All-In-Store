# All-In Store

Catalogo en Angular 21 con TailwindCSS + DaisyUI, Supabase y componentes standalone.

## Configuracion de Supabase

Defini las claves en los environments:

- `src/environments/environment.ts`
- `src/environments/environment.development.ts`

Valores esperados:

- `supabaseUrl`
- `supabaseAnonKey`
- `whatsappPhone`

## Desarrollo

```bash
npm install
ng serve
```

Abrir `http://localhost:4200/products`.

## Build

```bash
ng build
```
